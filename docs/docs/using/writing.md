# Writing

Projects > New Project makes a folder. Inside a project, New File makes a text file (a `.txt` extension is added if you do not give one), New Folder makes a sub-folder. Manage switches the list into rename and delete mode; pick a file or folder and choose what to do with it. Back at the top of the list goes up a level, and from the top of Projects back to the main menu.

The names Back, New Project and Manage are reserved, because they are rows in the list.

## In the editor

| Keys | What |
| --- | --- |
| Arrows, Home, End, Page Up, Page Down | move the cursor |
| Shift + any of those | extend a selection |
| Ctrl-C, Ctrl-X, Ctrl-V | copy, cut, paste within the device |
| Backspace, Delete | delete backwards, forwards (or the selection) |
| Enter | new line |
| Ctrl-S or Esc | save and go back to the folder |
| Ctrl-Space or POWER | status panel: project, word count, last sync, battery |
| Ctrl-L or LIGHT | cycle the backlight |

Text wraps at word boundaries to the width of the screen. Long words that do not fit a line are broken at the edge. The cursor is a vertical bar or an underline, depending on the cursor setting.

Files are saved when you leave the editor. There is no autosave while typing, so leave the editor before you power off. A file that fails to save (no SD card, say) stays open with a message instead of being lost.

## Layouts

Letters follow the layout chosen in Settings > Keyboard: QWERTY, QWERTZ, AZERTY or Dvorak. The number row and punctuation stay as on a US keyboard. Ctrl chords are keyed by physical position, so Ctrl-S is the same key on every layout.
